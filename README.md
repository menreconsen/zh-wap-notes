# zh-wap-notes

本仓库用于归档和发布一系列独立 HTML 页面。这些页面以轻量、自包含的方式呈现信息，不依赖外部框架或后端服务。

## 项目简介

`zh-wap-notes` 是一个以 HTML 页面为基本单元的归档仓库。每个页面均可独立浏览，适合快速查阅或离线保存。仓库不针对任何特定域名或网站，仅作为内容展示与分发的载体。

## 目录说明

```
.
├── index.html          # 仓库入口页（可选）
├── pages/              # 存放所有独立 HTML 页面
│   ├── example.html
│   └── ...
└── assets/             # 公共资源（CSS、图片等）
    └── ...
```

- `pages/`：主要页面目录，每个 `.html` 文件代表一个独立页面。
- `assets/`：页面共享的静态资源，可按需组织。

## 页面归档说明

- 所有页面均为纯 HTML 实现，可离线打开。
- 页面内容可能包含文本、图片、样式及简单交互。
- 归档内容会不定期更新，不保证持续维护或兼容性。
- 每个页面文件命名应清晰反映其内容主题。
